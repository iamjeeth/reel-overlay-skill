# Preferred music

Put LICENSED audio files of the songs listed in TASTE.json here (file name containing the title, e.g. `Dark Red - Steve Lacy.mp3`).
When a reel's mood matches a track's moods, the renderer uses it before the Pixabay collection (`music="auto"`), or force it with `music="liked"`.
The skill never downloads commercial recordings. Without a licensed file, render with `music=None` and add the song in the Instagram app, which carries the licence.
These files are git-ignored.
